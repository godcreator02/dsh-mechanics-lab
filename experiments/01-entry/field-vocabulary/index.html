01-entry / field-vocabulary

条目能写哪些字段

六个字段是权威清单的全部——patch 里写别的键不报错，只是没人读。

档次 ① 📗 复述型 ✅ 3 条用例 不需要 web

这一项讲的是什么

条目（entry：配方里的一行，写着挂哪个插件、给它什么配置——见 00-base/minimal-profile）能写的字段不是随便什么都算数的。loader 解析条目时按一份固定的接口去读，接口之外的键即使写了也不会被拿来做任何事。 这一项要讲清楚的，就是这份接口长什么样：一共几个字段、各管什么活、缺一个会怎样、 多写一个又会怎样。

条目能写的六个字段

权威清单定义在 cordis-plugin-loader 的 src/config/entry.ts，接口名叫 EntryOptions，一共六个字段， loader 不认识清单之外的任何键。下表按接口里的声明顺序列出每个字段管什么、 是否必填；最后一列是本项归档里实测出现过的情况。

字段管什么必填与否本项组合树里出现过
id 这条条目在树里的稳定地址，patch 靠它定位、后续修改这条条目——跟插件叫什么名字无关 必填是
name loader 拿它去 Node 做模块解析（import）的说明符——对包型插件，这就是包名 必填是
config 传给插件 apply(ctx, config) 的第二个参数 可选是
disabled 挂不挂这条条目（及它的子孙）；可以写布尔，也可以写 !!js 表达式延迟求值 可选否
group 把这条标成一个嵌套的条目组，config 变成子条目数组 可选否
inject 这条条目需要哪些服务，覆盖或补充插件代码里自己声明的依赖 可选否
野字段（举例，不在清单内） 权威清单之外的任意键——本项 patch 里真写了一个 野字段: "loader 不认识我" 不适用出现过，但被忽略：原样进组合树、不阻断加载、不报任何警告

本项唯一一次跑 test_entry_field_vocabulary，dump 里出现过的字段集合是 ['config', 'id', 'name']，对照权威清单 ['config', 'disabled', 'group', 'id', 'inject', 'name']——上表最右列 就是这次对比的结果，取自 results/20260817-151009/summary.md。

两处现场：id 换了别名、patch 塞了野字段

下面两个 profile 各自的 cordis.patch.yml 都只挂了同一个教学 插件 lab-entry——完整文件在右边文件树里可以点开看。插件本身很简单： apply() 把 marker、moduleLoadedAt、appliedAt 和收到的 config 写进一份见证文件，仅此而已；见证文件存在且 marker 对得上，就说明这次 apply() 真的跑过。

alias profile —— id 跟 name 毫无关系

patch 里写的是 id: 完全不像包名的别名，name: lab-entry—— 两个字段故意给成不相干的值。

unknown profile —— patch 里塞了个野字段

patch 在 id / name / config 之外， 还多写了一行 野字段: "loader 不认识我"——这个键不在 EntryOptions 里。

dump 里能看到它原样在场；插件同样照常加载， w-unknown.json 里 marker 对得上：

读出来的判定

①

一个条目只有六个字段。真实组合树里出现过的字段，是 EntryOptions 这六个（id/name/config/disabled/ group/inject）的子集——本项没写的三个（disabled/ group/inject）各自具体怎么起作用，不是这一项要回答的问题。 test_entry_field_vocabulary

②

patch 能塞任意键，但只有六个会被读。野字段被原样带进组合树、 --dump-config 里看得见，但不阻断加载、不报任何警告——字段名写错 （比如把 disabled 拼成 disable）不是「非法」，只是「没人读」。 test_unknown_field_is_carried_but_ignored

③

id 是树内地址，name 是 Node 模块解析名，两者互不相干。 loader 拿 name 去 resolve 模块，拿 id 在树里定位条目；把 id 改成跟包名毫无关系的字符串，插件照常加载——后续 patch 想改这条 条目，用的是 id，不是包名。 test_id_and_name_are_independent

判定与证据出处在 test_field_vocabulary.py 的模块 docstring，此页只负责让你看懂。

/**
 * field-vocabulary 用的教学插件：靠写见证文件证明 apply 执行过、
 * config 原样送达。除了 marker / moduleLoadedAt / appliedAt 三个指纹，
 * 没有别的行为——它自己不该成为任何一条判定的解释。
 */

import { writeFileSync } from "node:fs";

const MARKER = "field-vocabulary-v1";
const moduleLoadedAt = new Date().toISOString();

export function apply(ctx, config) {
  const witness = config?.witness;
  if (!witness) {
    throw new Error("lab-entry: config.witness 是必需的");
  }

  writeFileSync(
    witness,
    JSON.stringify(
      {
        marker: MARKER,
        moduleLoadedAt,
        appliedAt: new Date().toISOString(),
        config,
      },
      null,
      2,
    ),
    "utf8",
  );
}
