05-reload / new-code-old-config

新代码配旧配方

同一时刻改代码又改配方，代码热重载与配置各自的重载路径互不相通——拿到的是谁的新值。

档次 ① 🔬 发现型 ✅ 满覆盖 · 1 条用例 不需要 web

这一项讲的是什么

条目（entry，见 00-base/minimal-profile）挂载之后是一个活的 fiber——同一个插件实例这一次生命的载体。apply(ctx, config) 只在建它那一刻跑一次，config 参数是这个 fiber 出生时收到的那份快照，代码想再看到新值只能等自己被重新实例化。改一个条目，有两条互不相通的路：改它背后的代码文件——归 hmr（cordis-plugin-hmr 提供的服务，热重载的执行者）管，它盯哪棵目录树见 05-reload/watch-root；或者改贡献它 config 的那份 patch（对条目列表的一次编辑指令，完整语义见 02-recipe/insert-semantics）——而贡献 config 的 patch 本身还分层：一个 npm 包如果在自己 package.json 的 dsh.bundle.patch 字段里指了一份 YAML，profile 只要在 dsh.profile.bundles 名单里点这个包的名字，这份 YAML 就作为 bundle 层参与组合；与它相对的是活层——profile 自己那份 cordis.patch.yml 与 $DSH_HOME 那份 cordis.patch.yml，用户随时会手改的两份文件。这一项讲的是：当同一个条目的代码文件和它 bundle 层的 config 文件在同一时刻各自被改，代码那条路和 config 那条路分别走到哪一步，新 fiber 最终用的是谁的新值。

机制怎么工作

走一遍改动发生之后，代码那条路（hmr 的 root watcher）与 config 那条路（registerConfig）各自怎么处理：①②是 root watcher 自己的分支，③④是另一套专门盯 config 精确路径的独立机制。

同一时刻，两处各改一笔

用例起手 1 秒后，在同一个时间点分别改了 index.js 里写死的 版本字符串，和这个包自己那份 cordis.patch.yml 里 config.版本 字段——一次改动，代码与 config 各挪一格。

读出来的是什么

①

新代码配旧配方。代码热重载走 oldFiber.parent.registry.plugin(plugin, oldFiber._config, ...)，沿用的是旧 fiber 已经在跑的那份 _config，不是重新读盘的新值。 test_code_reload_keeps_the_old_config

②

bundle 层的 config 是冷的，而且是「看见了没人管」，不是「没看见」。watcher 确实报了一次 hmr-change 点名这份 patch 文件——它落在 hmr 的 root 范围里；但它既不是任何 loader.entries() 条目的 Include.filename，也没进 loadCache（YAML 不会被 import()），三条分支都接不住它。 同上

③

重启之后两笔改动才一起生效。新进程重新走 loadProfile()/composeProfile()，这次两份文件都是第一次真正被读盘，代码与 config 一起翻到新值——坐实的是「冷」，不是「丢了」。 同上

·

补充（源码依据，未实测）：全仓库只有两个 registerConfig 调用点——<profile>/cordis.patch.yml 与 $DSH_HOME/cordis.patch.yml，都不含 bundle 层。这个精确计数来自 grep dsh-app-boot 源码（runProfile() 里两次 watchUserPatches() 调用），没有对应的用例断言过「确实只有两个」——机制本身（bundle 层冷、活层两处热）已由上面三条坐实，缺的只是这句「仅此两处」的穷举断言。

/**
 * 纯算法文件，本项用例不改它，只是 index.js 依赖它才能跑。
 */

export function compute() {
  return "算法第一版";
}

/**
 * 教学插件——一个包，声明了 `dsh.bundle`，条目由包自己那份 patch 生。
 *
 * 报两个版本号，来路不同：
 *   版本     —— 写死在这个文件里，改它是「改代码」
 *   配置版本 —— 从条目的 config 来，改它是「改配方」
 * 本项用例同一时刻改这两处，看重载之后拿到的是哪一头的新值。
 */

import { compute } from "./helper.js";

export const inject = ["labObserver"];

export function apply(ctx, config) {
  const say = ctx.labObserver.for(ctx);

  say("我跑起来了", {
    版本: "第一版",
    配置版本: config?.版本 ?? null,
    算出来: compute(),
  });
}
