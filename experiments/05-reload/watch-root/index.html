「拆干净再建」是错觉。旧的进 UNLOADING 之后、真正 DISPOSED 之前， 新的已经开始 LOADING 了；hmr 报「重新加载了」时旧的还活着。 1322.1 UNLOADING → 1322.6 新的 LOADING → 1322.9 旧的 DISPOSED
